# BJTlogiggateproject
aims to create faster and more energy efficient BJT logic gates and tries to maintain itself cooler than 30°C

Currently testing with PCB designing, I'm trying to build a 4bit adder and turn it into a fully working pCB, once I know how to correctly make,
I'll try to bring my logic up to faster speeds.
I made this project because I love transistors and how PCs work, so I decided to exeperience myself in first person.

Using my preject is actually very simple, it's just a 4bit adder, you can add 4bit numbers together to gain the sum of them! No further knowledge is required.
You only need to know basic transistor logic and how binary works.
